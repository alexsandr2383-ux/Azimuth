# Азимут (Azimuth)

![CI](https://github.com/alexsandr2383-ux/Azimuth/actions/workflows/ci.yml/badge.svg)

Офлайн-навигация для эндуро и мотопутешествий. Приложение работает без интернета: карты,
рельеф, запись треков, маршруты по дорогам и тропам — всё из локальных данных `NavData/`.

Платформы: **Android** (основная, фоновая запись через foreground service) и **Windows/десктоп**
(одна кодовая база Kotlin Multiplatform). Стек: Kotlin 2.x + Compose Multiplatform,
MapLibre (Android view + Desktop canvas), kotlinx.serialization, Gradle 8 / JDK 17.

## Возможности

- **Карты и слои** — базовая/спутниковая подложка, XYZ-источники по ссылке, импорт `.mbtiles`,
  скачивание областей для офлайн-просмотра, наложения с прозрачностью, рельеф-тени из DEM.
- **Запись треков** — пресеты точности (1/3/10 с), запись в фоне при заблокированном экране,
  продолжение трека после паузы, пропуск точек на остановках, автосохранение и восстановление
  после сбоя, барометр как запасной источник высоты (на устройствах с датчиком).
- **Ведение по треку** — предстартовый экран: реверс, петля, авто-цель (старт с ближайшей точки),
  порог отклонения; предупреждение «СХОД С МАРШРУТА» и «ТРОПА, не дорога» на маршруте.
- **Маршруты** — построение по дорогам/тропам под профиль транспорта (эндуро/пешеход),
  расчёт топлива («на сколько км хватит бака» с учётом трамплинов и резерва).
- **Коллекции** — журнал треков с плитками статистики и графиком высот, сравнение записи
  с маршрутом, экспорт GPX/PNG/PDF, корзина «Недавно удалённые».
- **Точки и POI** — свои точки с фото и голосовыми заметками, категории (вода, еда, топливо,
  медицина, ночлег…), POI из OpenStreetMap по выбранной области (Overpass + офлайн-кэш),
  офлайн-поиск по точкам и координатам.
- **Справка и безопасность** — зоны запретов/ООПТ из OSM, расчёт светового дня с учётом
  рельефа, компас-стрелка местоположения, резервные копии и синхронизация `NavData`
  по USB/Wi-Fi, встроенная офлайн-справка.

## Сборка

```bash
./gradlew :composeApp:desktopTest   # unit-тесты core (JVM)
./gradlew :composeApp:assembleDebug # APK: composeApp/build/outputs/apk/debug/composeApp-debug.apk
```

- `composeApp/src/commonMain/core` — вся логика (роутинг, треки, DEM, POI) без зависимостей от UI.
- `composeApp/src/androidMain`, `composeApp/src/desktopMain` — платформенные реализации
  (GPS-сервис, MapLibre, хранилище, компас, барометр).
- CI: GitHub Actions — тесты + сборка APK на каждый push (см. `.github/workflows/ci.yml`).

## Данные (NavData)

Приложение хранит всё в папке `NavData` (на Android — `Android/data/ru.azimut.app/files/NavData/`):
треки, точки, карты, DEM, POI, фото, голосовые заметки, резервные копии. Папка переносима:
скопировав её, вы переносите все данные на другое устройство или на десктоп.
